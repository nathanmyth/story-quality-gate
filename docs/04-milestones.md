# Milestones

Aligned to SAFe cadence: two iterations to a working gate, then a PI of piloting.

| # | Milestone | Key deliverables | Exit criteria | Target |
|---|---|---|---|---|
| **M1** | Rubric & foundations | PRD, SAFe rubric mapping, `rubric.json` reviewed with RTE and 2 POs, repo + CI | Rubric signed off; CI green | Iteration 1 |
| **M2** | Gate + Jira integration | Scorer, gate, Jira client (dry run + live), CLI, Streamlit UI, eval set | Eval targets met; test story created in a sandbox Jira project | Iteration 2 |
| **M3** | Calibration | 50 real stories labeled by 2–3 POs who haven't seen the rubric; tune rubric; AI coach | Agreement ≥ 90%, false accepts 0% on the *real* set | Iteration 3 |
| **M4** | Pilot on one ART | 2 teams use the gate for all new stories for one PI; retro | Carry-over trend measured; PO satisfaction ≥ 4/5 | PI + 1 |

## Critical path
Rubric sign-off → Jira sandbox access → calibration labels. **Jira admin access is the external dependency most likely to slip.** Request it in Iteration 1.
