# Pilot Launch Checklist (Go / No-Go)

## Gate quality — P0
- [ ] False accepts = 0% on the calibration set (real stories, blind PO labels)
- [ ] Agreement with POs ≥ 90%
- [ ] Every lost point shows actionable feedback

## Jira integration — P0
- [ ] Story created successfully in a sandbox project, with correct summary, description, labels, and story points
- [ ] Service account with project-scoped permissions; token stored as a secret
- [ ] Jira error messages shown clearly to the user (tested with a wrong project key)

## Ways of working — P1
- [ ] RTE and Scrum Masters agree the rubric reflects the ART's Definition of Ready
- [ ] PO quick guide: how to read the scorecard and use the coach
- [ ] Agreement that scores are reported at ART level only

## Operations — P1
- [ ] Rubric owner named; change process = pull request reviewed by RTE
- [ ] Decision log reviewed at the end of each iteration
- [ ] Rollback: POs create stories directly in Jira as before
